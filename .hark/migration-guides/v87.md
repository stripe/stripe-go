# Migration guide for v87

This version uses API version `2026-09-30.endive`.  If the format of this API version looks new to you, see our new [API release process](https://stripe.com/blog/introducing-stripes-new-api-release-process).

Please review our API changelog for `2026-09-30.endive` to understand all the breaking changes to the Stripe API, the reasons behind them and potential alternatives.

The Go SDK specific changelog for v85 has the corresponding changes in the SDKs as well as SDK specific breaking changes.

## Minimum Go version raised to 1.24

Go versions 1.22 and 1.23 are no longer supported. The package now requires Go \>= 1.24.

**Action required**: Upgrade to Go 1.24 or later before updating to the latest SDK version. For more information, see our [language version support policy](https://docs.stripe.com/sdks/versioning?lang=go#stripe-sdk-language-version-support-policy).

Note that this is the last major release that supports Go `1.24`. Please make plans to update to Go `1.25` or higher before March 2027.

## Decimal API fields now use exact decimal types

v87 changes decimal API fields from `float64` and `*float64` to `decimal.Decimal` and `*decimal.Decimal`. This prevents large or highly precise values from being rounded during floating-point conversion.

### Update request values

Before v87, decimal request fields used `*float64`:

```go
value, err := strconv.ParseFloat(input, 64)
if err != nil {
	return err
}
params := &stripe.PriceParams{
	UnitAmountDecimal: stripe.Float64(value),
}
```

In v87, parse input with `decimal.NewFromString` and use `stripe.Pointer` for nullable fields:

```go
import (
	"github.com/shopspring/decimal"
	"github.com/stripe/stripe-go/v87"
)

value, err := decimal.NewFromString(input)
if err != nil {
	return err
}
params := &stripe.PriceParams{
	UnitAmountDecimal: stripe.Pointer(value),
}
```

For fixed values where invalid input should be a programming error, use `decimal.RequireFromString`:

```go
params := &stripe.PriceParams{
	UnitAmountDecimal: stripe.Pointer(decimal.RequireFromString("0.0123456789")),
}
```

### Read response values

Use decimal methods instead of converting response values to `float64`:

```go
expected := decimal.RequireFromString("0.0123456789")
if price.UnitAmountDecimal.Equal(expected) {
	fmt.Println(price.UnitAmountDecimal.String())
}
```

The package also provides arithmetic and rounding methods.
