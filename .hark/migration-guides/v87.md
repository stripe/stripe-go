# Migration guide for v87

v87 of the SDK changes fields represented as decimal strings by the Stripe API from `float64` and `*float64` to `decimal.Decimal` and `*decimal.Decimal`. This is a source-breaking change that prevents large or highly precise values from being rounded by IEEE-754 floating-point conversion.

## Update request values

Before v87, decimal request fields accepted `*float64`:

```go
package main

import (
	"strconv"

	"github.com/stripe/stripe-go/v86"
)

func oldPriceParams(input string) (*stripe.PriceParams, error) {
	value, err := strconv.ParseFloat(input, 64)
	if err != nil {
		return nil, err
	}
	return &stripe.PriceParams{UnitAmountDecimal: stripe.Float64(value)}, nil
}

func main() {
	_, _ = oldPriceParams("12345678901234567890.123456789012")
}
```

In v87, parse validated runtime input with `decimal.NewFromString` and use `stripe.Pointer` for nullable request fields:

```go
package main

import (
	"github.com/shopspring/decimal"
	"github.com/stripe/stripe-go/v87"
)

func priceParams(input string) (*stripe.PriceParams, error) {
	value, err := decimal.NewFromString(input)
	if err != nil {
		return nil, err
	}
	return &stripe.PriceParams{UnitAmountDecimal: stripe.Pointer(value)}, nil
}

func main() {
	_, _ = priceParams("12345678901234567890.123456789012")
}
```

For constants and examples where invalid input should be a programming error, use `decimal.RequireFromString`:

```go
package main

import (
	"github.com/shopspring/decimal"
	"github.com/stripe/stripe-go/v87"
)

func main() {
	params := &stripe.PriceParams{
		UnitAmountDecimal: stripe.Pointer(
			decimal.RequireFromString("12345678901234567890.123456789012"),
		),
	}
	_ = params
}
```

## Read and compare response values

Response fields now expose decimal operations directly. Compare values with `Equal` rather than converting them to `float64`:

```go
package main

import (
	"fmt"

	"github.com/shopspring/decimal"
	"github.com/stripe/stripe-go/v87"
)

func hasExpectedAmount(price *stripe.Price) bool {
	expected := decimal.RequireFromString("12345678901234567890.123456789012")
	return price.UnitAmountDecimal.Equal(expected)
}

func main() {
	price := &stripe.Price{
		UnitAmountDecimal: decimal.RequireFromString("12345678901234567890.123456789012"),
	}
	fmt.Println(price.UnitAmountDecimal.String())
	fmt.Println(hasExpectedAmount(price))
}
```

Use the arithmetic and rounding methods provided by `github.com/shopspring/decimal` when calculations are needed.

## Serialization behavior

`decimal.Decimal` implements JSON and text marshaling. Decimal API response values continue to decode from quoted JSON strings, and request structs marshal decimal values as quoted JSON strings. Form-encoded requests send the exact decimal text without converting through `float64`.

The `github.com/shopspring/decimal` module is now a public dependency of stripe-go. Applications that refer to decimal fields directly should import that module as shown above.
