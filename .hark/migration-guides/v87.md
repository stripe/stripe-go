## Free-form API dictionaries use `map[string]any`

`PaymentIntentNextAction.UseStripeSDK` and `SetupIntentNextAction.UseStripeSDK` now use `map[string]any` so that stripe-go retains arbitrary keys returned by the Stripe API. The empty `PaymentIntentNextActionUseStripeSDK` and `SetupIntentNextActionUseStripeSDK` types have been removed.

Code that explicitly names either removed type must use a dynamic map instead. For example:

```go
var details *stripe.PaymentIntentNextActionUseStripeSDK = paymentIntent.NextAction.UseStripeSDK
```

becomes:

```go
var details map[string]any = paymentIntent.NextAction.UseStripeSDK
```

The equivalent change applies to `SetupIntentNextActionUseStripeSDK`. Existing code that only checks whether `UseStripeSDK` is `nil` does not need to change. Values can be read with map lookups and type assertions:

```go
value, ok := paymentIntent.NextAction.UseStripeSDK["key"].(string)
```
