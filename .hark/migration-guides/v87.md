# Migration guide for v87

## Decimal API fields now use exact decimal types

v87 changes decimal API fields from `float64` and `*float64` to `decimal.Decimal` and `*decimal.Decimal`. This prevents large or highly precise values from being rounded during floating-point conversion.

### Update request values

Before v87, decimal request fields used `*float64`:

```go
value, err := strconv.ParseFloat(input, 64)
if err != nil {
	return err
}
params := &stripe.PriceParams{
	UnitAmountDecimal: stripe.Float64(value),
}
```

In v87, parse input with `decimal.NewFromString` and use `stripe.Pointer` for nullable fields:

```go
value, err := decimal.NewFromString(input)
if err != nil {
	return err
}
params := &stripe.PriceParams{
	UnitAmountDecimal: stripe.Pointer(value),
}
```

Import `github.com/shopspring/decimal`. For fixed values where invalid input should be a programming error, use `decimal.RequireFromString`:

```go
params := &stripe.PriceParams{
	UnitAmountDecimal: stripe.Pointer(decimal.RequireFromString("0.0123456789")),
}
```

### Read response values

Use decimal methods instead of converting response values to `float64`:

```go
expected := decimal.RequireFromString("0.0123456789")
if price.UnitAmountDecimal.Equal(expected) {
	fmt.Println(price.UnitAmountDecimal.String())
}
```

The package also provides arithmetic and rounding methods.

### Serialization

No additional serialization changes are needed. Decimal response values decode from quoted JSON strings, while JSON and form requests preserve their exact decimal text.
